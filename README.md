# Learning Coach for Trae 🧠

> **不仅教你学什么，更是教你怎么学** —— 基于元认知监控模型的学习教练，专为 **Trae IDE** 优化，让 AI 成为你的第二大脑和沉浸式学习伙伴。

## 核心思想

### 元认知监控循环

基于 Nelson & Narens (1990) 的元认知监控模型，Learning Coach 现在明确区分：

```
元层（Meta-level）：监控学习状态 → 生成控制决策
对象层（Object-level）：执行当前任务 → 产生新的学习表现
```

两层之间通过一个持续循环连接：

```
对象层任务执行 → 元层监控评估 → 元层控制决策 → 返回对象层执行
```

**为什么有效？**

传统学习往往缺乏"自我监控"——你不知道自己是否真正掌握了某个概念。元认知监控通过不断评估和调整，让学习变成一个**可迭代、可量化、可记录**的过程。Learning Coach 会保存：

- 最近一次掌握度评估
- 最近一次控制策略
- 监控历史与认知循环记录
- 当前任务与下一步任务建议

### 三层掌握度模型

Learning Coach 将"掌握"分为三个层次：

| 层次               | 定义           | 权重 |
| ------------------ | -------------- | ---- |
| **表层理解** | 能识别、能回忆 | 20%  |
| **语义理解** | 能解释、能说明 | 30%  |
| **直觉理解** | 能应用、能举例 | 50%  |

只有当**直觉理解**达到一定水平，才算真正掌握。这也是为什么我们强调在 Trae 中进行"动手实践"和"编写代码"。

### 个性化学习策略

系统根据当前掌握度自动推荐策略：

| 掌握度范围 | 推荐策略                             |
| ---------- | ------------------------------------ |
| 0% - 30%   | 入门视频 → 基础文章 → 前置知识补充 |
| 30% - 60%  | 进阶文章 → 练习题 → 动手实践       |
| 60% - 80%  | 项目实践 → 教给他人 → 新场景应用   |

### 领域任务树

Learning Coach 不再只依赖通用五阶段模板，而是优先按主题识别领域并生成更贴近对象层任务的学习路径。目前内置：

- **AI/机器学习**：问题定义 → 核心机制 → 数据表示 → 训练调参 → 应用落地
- **编程语言/框架**：语法模型 → 运行机制 → 项目结构 → 调试测试 → 项目迁移
- **BIM/工程数字化**：业务目标 → 数据解析 → 图表示建模 → 规则/算法设计 → 闭环优化
- **数据工程/数据系统**：数据链路 → 存储建模 → 处理调度 → 稳定性排查 → 应用复盘
- **通用回退模板**：当主题无法识别时，自动回退到通用学习路径

这样做的目的，是让对象层任务更贴近真实领域，从而让元层的监控和控制建议更具体。

### 苏格拉底式追问 (v1.2.0)

基于6维度追问框架，帮助零基础学习者深度思考：

```
澄清 → 假设 → 证据 → 视角 → 后果 → 反思
```

**特点**：

- **自动启用**：零基础用户建档时自动启用 SOCRATIC_PRIORITY 模式
- **最多3轮**：每个学习目标最多3轮追问，避免过度追问
- **随时退出**：输入"直接解释"可跳过追问，获得直接讲解
- **维度循环**：按顺序探索6个认知维度

## 在 Trae 中如何使用？

Learning Coach 可以与 Trae IDE 的 AI 助手（Chat / Builder）无缝结合，提供沉浸式的代码学习体验。

### 方式一：让 Trae AI 扮演教练（推荐）

你可以直接在 Trae 的 Chat 窗口中输入以下 Prompt，让 Trae 化身为你的专属学习教练：

```text
请你扮演 Learning Coach，基于元认知监控模型（任务选择 → 掌握评估 → 策略调整）来指导我学习。
请帮我建立学习档案，了解我的基础和目标。在讲解核心概念时，请使用苏格拉底式追问（澄清 → 假设 → 证据 → 视角 → 后果 → 反思）引导我思考，而不是直接给出答案。
现在，我想学习：[输入你想学的技术/语言/框架，例如：React Hooks]
```

**结合 Trae 的优势**：
- **代码结合**：在追问过程中，你可以直接选中编辑器中的代码，问教练 "这段代码体现了什么假设？"
- **动手实践**：当掌握度达到 60% 时，直接让 Trae Builder 在当前工作区为你生成一个练习项目或测试用例。

### 方式二：使用内置命令行交互

如果你更喜欢结构化的终端交互，可以直接在 Trae 的内置终端中运行 Coach 脚本：

1. 使用快捷键打开 Trae 终端。
2. 运行以下命令：

```bash
# 确保安装了所需依赖（如果需要）并执行
python scripts/coach.py start 机器学习

# 零基础模式（自动启用苏格拉底追问）
python scripts/coach.py start 机器学习 --level 零基础

# 进入全功能交互模式
python scripts/coach.py
```

在交互模式下，你可以使用：
- `status` - 查看进度
- `list` - 列出所有学习目标
- `mindmap` - 生成思维导图，保存到 `mindmaps/<主题>/` 目录下
- `socratic [知识点]` - 开始苏格拉底式评估
- `answer "[你的回答]"` - 回答教练的追问
- `explain` - 退出追问，获取直接讲解

## 功能特性

- ✅ **元认知监控循环** - 显式区分监控与控制，持续评估掌握度并生成策略
- ✅ **沉浸式代码学习** - 结合 Trae IDE 的 Chat 和 Builder，边写边学
- ✅ **断点续学** - 自动保存进度，随时继续
- ✅ **多目标管理** - 同时追踪多个学习主题
- ✅ **认知循环记录** - 完整记录每次学习过程
- ✅ **学习路径初始化** - 新主题自动生成默认学习路径与首个当前任务
- ✅ **领域任务树生成** - 按主题自动匹配领域蓝图，生成更贴合语境的任务树
- ✅ **思维导图生成** - 按学习主题保存到 `mindmaps/<主题>/`，便于分类管理与持续复盘
- ✅ **苏格拉底式追问持久化** - 跨命令保持追问会话，并在结束时落盘评估与策略

## 核心算法

### 掌握度计算

```python
def calculate_mastery(answers):
    """
    表层理解 × 0.2 + 语义理解 × 0.3 + 直觉理解 × 0.5 = 综合掌握度
    """
    return (
        answers["surface"] * 0.2 +
        answers["semantic"] * 0.3 +
        answers["intuitive"] * 0.5
    )
```

### 任务优先级

```python
def select_task(tasks):
    """
    优先级排序：
    1. 未开始的任务优先
    2. 重要性高的任务优先
    3. 掌握度低的任务优先（薄弱点优先攻克）
    """
    incomplete = [t for t in tasks if t["mastery"] < 0.8]
    incomplete.sort(key=lambda t: (-t["importance"], t["mastery"]))
    return incomplete[0]
```
